Personal computer-science project

Benchmarking Minesweeper solvers, one seed at a time.

This site is a testbed for comparing solving algorithms — from simple local-deduction rules to probability-based guessing — against a fixed bank of 1000 reproducible levels. Every level is generated from a stored seed, so any solver, run at any time, opens the exact same grid from the exact same first click. That makes results comparable across methods and across runs.

How the levels work

Each level is generated once by generate_levels.py from a fixed master seed. The very first cell opened — and its up-to-8 neighbors — is guaranteed mine-free, so every implementation (this page's JS engine, or a Python solver reading levels.json) starts from an identical position. Same level id ⇒ always the same mine layout.
