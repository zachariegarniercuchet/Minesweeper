Comment jouer — règles classiques
  • La grille cache des mines. Un clic gauche révèle une case : si c'est une mine, la partie est perdue ; sinon, un chiffre indique le nombre de mines parmi les 8 cases voisines.
  • Si ce chiffre vaut 0, toutes les cases voisines s'ouvrent automatiquement, et ainsi de suite en cascade.
  • Un clic droit (ou le mode drapeau sur mobile) pose ou retire un drapeau 🚩 sur une case suspectée d'être minée.
  • Chord : cliquer sur une case déjà révélée dont le nombre de drapeaux voisins égale son chiffre révèle d'un coup toutes les autres cases voisines. Pratique, mais risqué si un drapeau est mal placé.
  • La partie est gagnée quand toutes les cases sans mine sont révélées — inutile de drapeauter chaque mine.
  • Au clavier : Tab pour naviguer entre les cases, Entrée/Espace pour révéler ou "chord", F pour drapeau/retirer.

Les 1000 niveaux du banc sont générés une fois pour toutes par generate_levels.py à partir d'un seed fixe : même id ⇒ toujours la même grille de mines et la même case de départ. Cela permettra de comparer plusieurs solveurs sur exactement les mêmes grilles à l'étape suivante.
