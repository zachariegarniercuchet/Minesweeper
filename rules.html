How to play

Classic Minesweeper rules

  • The grid hides mines. A left click reveals a cell: if it's a mine, the game is lost; otherwise a number shows how many mines sit among its up-to-8 neighboring cells.
  • If that number is 0, all neighboring cells open automatically, cascading outward until only numbered cells border the opened area.
  • A right click (or flag mode on mobile) places or removes a flag 🚩 on a cell you suspect holds a mine. Flagged cells can't be revealed until unflagged.
  • Chording: clicking an already-revealed number whose count of flagged neighbors equals that number instantly reveals all its remaining neighbors. Fast, but risky if a flag is misplaced.
  • The game is won once every non-mine cell is revealed — you don't need to flag every mine.

Keyboard controls

  • Tab — move between cells
  • Enter / Space — reveal, or chord if already revealed
  • F — toggle a flag

Reproducible levels

The 1000 levels in the bank are generated once, ahead of time, from a fixed master seed. Given the same level id, the mine layout and starting cell are always identical — on this page, and in any Python solver reading the same levels.json. That's what makes it possible to compare different solving algorithms fairly: they all face exactly the same boards.

On the first click of a level, the opened cell and its neighbors are guaranteed to be mine-free — so no level ever forces a first-move guess.
